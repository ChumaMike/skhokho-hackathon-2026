# docs/legal — register of open points

GENERATED by `scripts/legal/sync-legal-texts.mjs` (`npm run legal:sync`) — do not edit by hand; `npm run legal:check` and the unit suite fail when this file is stale.

Every document in this folder is a **DRAFT FOR ATTORNEY REVIEW**. None has been reviewed by counsel, none is in force, and the app says so wherever it shows one:

- `/terms` and `/privacy` render the markdown with a "Draft for attorney review — not yet in force" badge while `draft` is true in `src/lib/legal/documents.ts`, and the version string itself (`v0.1-draft-…`) says draft.
- the checkout and booking consent lines link to those pages and record the version shown; they make no claim that the text is final.
- the storefront footer's ECTA s43 block shows the business's own details and links to `/terms` and `/privacy`; it carries no statement about the status of the platform texts.
- the driver terms and driver privacy notice are not served by the app at all until `DRIVER_TERMS_*` / `DRIVER_PRIVACY_*` point at published documents.

Two kinds of marker appear inline. **[ATTORNEY: …]** is a point counsel must decide or confirm. **[FILL IN: …]** is a fact Skhokho Laboratory ("Skhokho Labs") must supply before publication. Neither may remain in a published version.
